# 🍎 사과게임

숫자 사과를 이어 합의 10의 배수를 만들고 제한시간 안에 높은 점수를 노리는 브라우저 퍼즐 게임입니다.

## 게임 소개

게임을 시작하면 1부터 9까지의 숫자가 담긴 사과 64개가 8 × 8 밭에 나타납니다. 상하좌우로 이웃한 사과를 드래그해 선택하고, 놓았을 때 합이 10의 배수라면 수확에 성공합니다. 선택한 숫자의 합만큼 점수를 얻습니다.

수확한 사과가 사라지면 각 열의 사과가 아래로 내려오고, 위쪽 빈자리는 새 사과로 채워집니다. 제한시간은 1분이며, 최고 점수는 브라우저에 저장되어 다음 방문에도 확인할 수 있습니다.

## 기술 구성

- HTML로 게임 화면과 점수·타이머 영역을 구성했습니다.
- CSS로 과수원 분위기의 반응형 화면과 사과 숫자 칸, 선택 효과, 폭죽 애니메이션을 만들었습니다.
- Vanilla JavaScript로 보드 생성, 인접 칸 드래그, 합계 판정, 점수 저장, 열 낙하와 타이머를 구현했습니다.
- 별도의 프레임워크나 빌드 도구 없이 브라우저 기능만 사용합니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 목표 합을 10 고정에서 10의 배수로 확장했습니다.
- 2분 대신 1분 제한시간을 적용하고, 시작 버튼을 눌러야 게임이 진행되도록 했습니다.
- 숫자 칸에 사과 아이콘을 표시하고 숫자를 아이콘 중앙에 배치했습니다.
- 수확 뒤 빈칸이 남지 않도록 열 단위로 사과를 내리고 위쪽을 새 숫자로 보충합니다.
- 최고 점수를 `localStorage`에 기록하며, 시간이 끝나면 5초 동안 폭죽 효과를 재생합니다. 기기에서 동작 줄이기 설정을 사용 중이면 폭죽 애니메이션은 표시하지 않습니다.
